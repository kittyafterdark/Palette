# Palette 1.0.0

Palette's first public release: a visual, component-aware theme editor for Lumiverse.

## Highlights

- Semantic element picking and reusable component-aware scopes.
- Visual style packets for color, typography, spacing, layout, images, effects, positioning, pseudo-elements, responsive behavior, and more.
- Base + Mobile authoring and Normal / Hover / Active / Focus / Disabled states.
- Smart Guides, Layout Groups, Read Style / Read Page, My Styles, Quick Looks, and theme projects.
- Native Lumiverse theme handoff while keeping Palette's generated CSS and Custom CSS separate.
- Built-in Manga, Editorial, Visual Novel, and Journal directions with mounted desktop/mobile QA across BubbleMessage and MinimalMessage.
- Mobile workbench with safe scroll gutters, compact controls, clearer toolbar grouping, Minimize semantics, and a contained 100% → 80% → 60% density cycle.

## Compatibility

- Palette project/state schema: **v41**
- Minimum Lumiverse version: **1.1.6**
- Permission requested: `app_manipulation`

## Install

Install Palette from its GitHub repository through **Lumiverse → Extensions → Install Extension** and grant the requested permission. The repository commits its built `dist/` runtime, so no local build is required for normal installation.
